# Aviation Accident Analysis

This project explores aviation accident data using Python, pandas, Seaborn, and Matplotlib. The analysis examines patterns in injury severity and aircraft destruction across different aircraft types, flight phases, and weather conditions.

## Questions Explored

- How does the fatal/serious injury fraction differ between small and large aircraft?
- Which plane makes and models have the lowest mean injury fractions?
- How does aircraft destruction vary by flight phase?
- Is aircraft destruction associated with weather conditions?
- How do injury distributions differ across airplane types?

## Tools

- Python
- pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
